# Гибридная система рекомендаций книг с нейросетевым ранжировщиком (Goodbooks-10k)

Итоговый проект курса. Развивает [ДЗ №1](notebook.ipynb) (Popularity, Content, Item-CF, SVD, PureSVD):
модели из ДЗ становятся первым уровнем гибридной системы, поверх которого строятся расширенные
признаки, пул кандидатов, обучаемые ранжировщики (градиентный бустинг и нейросеть), слой разнообразия
и сквозной пайплайн.

- **[`final_project.ipynb`](final_project.ipynb)** — основной документ: все этапы, графики, анализ и выводы (выполнен, можно читать без запуска).
- **[`src/bookrec/`](src/bookrec/)** — код системы (ноутбук только вызывает его).
- **[`run_pipeline.py`](run_pipeline.py)** — сквозной пайплайн одной командой.
- [`notebook.ipynb`](notebook.ipynb) — ДЗ №1 без изменений.

## Структура

```
src/bookrec/
  config.py       все параметры в одном Config
  data.py         загрузка, очистка, split 80/20 внутри пользователя, выборки eval/tune/fit
  models/         popularity, content (TF-IDF), itemcf, svd (FunkSVD, PureSVD) — единый интерфейс score_user()
  features.py     признаки книг (29), пользователей (30): популярность, разброс оценок, жанры из тегов,
                  строгость, мейнстримность, энтропия вкуса
  candidates.py   пул кандидатов (top-50 от каждой модели) + признаки взаимодействий (79 признаков на пару)
  hybrid.py       WeightedBlend (веса по сегментам), LearnedRanker (HGB / LogReg), MMRReranker, HybridRecommender
  neural.py       NeuralRanker (MLP, PyTorch; BCE и pairwise-обучение), RankAverage (ансамбль)
  metrics.py      Precision@K, Recall@K, nDCG@K, Coverage, Personalization, ILD, бутстрэп, парный тест
  pipeline.py     Pipeline: данные → модели → признаки → пулы → гибрид → оценка → сервис → отчёт
scripts/make_notebook.py   генератор final_project.ipynb
run_pipeline.py            CLI пайплайна
```

## Запуск

```bash
pip install -r requirements.txt

# сквозной пайплайн (полный прогон ~25 мин на M1, повторный запуск за минуты благодаря кэшу в artifacts/)
python3 run_pipeline.py
python3 run_pipeline.py --quick --artifacts-dir artifacts_quick     # быстрая проверка, ~12 мин
python3 run_pipeline.py --data-dir <новые данные> --artifacts-dir <новая папка>   # новые данные того же формата

# ноутбук
python3 scripts/make_notebook.py && jupyter nbconvert --to notebook --execute --inplace final_project.ipynb
```

Пайплайн пишет в `artifacts/`: `metrics_summary.csv`, `metrics_by_segment.csv`, `plots/*.png`,
`sample_recommendations.csv`, `report.md`, обученные модели и ранжировщики.

## Архитектура

```
ratings, books, tags ─► split ─► 5 базовых моделей ─► пул кандидатов (≈185 книг / пользователь)
                                         │                    │
                              признаки книг и пользователей   признаки взаимодействий
                                         └──────────┬─────────┘
                                          ранжировщик (HGB + MLP, усреднение рангов)
                                                    │
                                              MMR (λ = 0.9) ─► top-10
холодный старт: новый пользователь → байесовская популярность; онбординг → Content + PureSVD
```

## Результаты (3 000 eval-пользователей, те же, что в ДЗ)

| Модель | Precision@10 | Recall@10 | nDCG@10 | Coverage | ILD |
|---|---|---|---|---|---|
| Popularity | 0.0006 | 0.002 | 0.001 | 0.2% | 0.71 |
| FunkSVD (surprise) | 0.0005 | 0.001 | 0.001 | 0.3% | 0.64 |
| Content (TF-IDF) | 0.045 | 0.168 | 0.129 | 69% | 0.59 |
| Item-CF | 0.052 | 0.149 | 0.137 | 80% | 0.80 |
| PureSVD | 0.068 | 0.193 | 0.163 | 56% | 0.71 |
| Гибрид ДЗ (PureSVD + Content, β=20) | 0.073 | 0.222 | 0.182 | 73% | 0.65 |
| Смешивание 5 моделей, веса по сегментам | 0.074 | 0.227 | 0.191 | 75% | 0.65 |
| Бустинг только на скорах моделей | 0.072 | 0.228 | 0.189 | 73% | 0.71 |
| Бустинг на всех 79 признаках | 0.086 | 0.276 | 0.233 | 73% | 0.74 |
| Нейросеть MLP (BCE) | 0.085 | 0.277 | 0.235 | 71% | 0.73 |
| Нейросеть MLP (pairwise) | 0.085 | 0.276 | 0.234 | 72% | 0.73 |
| Ансамбль бустинг + MLP | 0.087 | 0.278 | **0.236** | 71% | 0.73 |
| **Финал: ансамбль + MMR (λ = 0.9)** | **0.087** | **0.279** | **0.236** | 72% | 0.74 |

| Сегмент | Лучшая одиночная | Гибрид ДЗ | Финал | Прирост |
|---|---|---|---|---|
| холодные (≤ 5 оценок) | Content 0.124 | 0.138 | 0.202 | +62% |
| средние (6–20) | PureSVD 0.149 | 0.165 | 0.221 | +48% |

Парные бутстрэп-интервалы разниц с базовыми моделями и гибридом ДЗ целиком выше нуля.

## Главные выводы

1. **Признаки дают больше, чем смешивание моделей.** Бустинг, видящий только скоры пяти моделей,
   равен лучшему смешиванию (nDCG@10 ≈ 0.19). Признаки взаимодействия добавляют +14%, признаки
   пользователя и книги ещё +8%: итого 0.233, на 43% лучше PureSVD и на 28% лучше гибрида ДЗ.
   Самые важные признаки (permutation importance): максимальная близость к прочитанному в
   пространствах PureSVD и Item-CF, популярность книги относительно привычек пользователя, число
   понравившихся книг.
2. **Двухуровневая архитектура ничего не теряет.** Гибрид ДЗ на пуле из ≈185 кандидатов даёт ту же
   точность, что на всех 10 000 книгах, при ранжировании в 50 раз дешевле. Recall пула (≈0.45)
   становится главным ограничением сверху.
3. **Сегментация выучивается сама.** Оптимальные веса смешивания повторяют вывод ДЗ (Content для
   холодных, PureSVD для активных), а бустинг делает то же мягче через признаки активности и вкуса.
4. **Нейросеть на табличных признаках равна бустингу, а не лучше.** MLP (0.235) и HGB (0.233)
   статистически неразличимы, ансамбль даёт небольшой устойчивый прирост (+0.0035, CI > 0). Инференс
   MLP в 10 раз быстрее. Преимущество нейросети здесь в расширяемости (тексты, последовательности), а не в качестве.
5. **Разнообразие покупается осознанно.** MMR с λ = 0.9 добавляет +0.01–0.04 ILD и покрытие каталога при
   потере nDCG меньше 1% (на ансамбле nDCG даже не падает); штраф за автора оказался хуже чистого MMR.

Сильные и слабые стороны каждого метода, ограничения эксперимента и рекомендации по выбору моделей
разобраны в разделе 6 ноутбука.

## Протокол оценки

- Train/test 80/20 внутри каждого пользователя (времени оценок нет), релевантно = оценка ≥ 4 в тесте.
- Три непересекающиеся выборки: `eval_users` (3 000, итоговые метрики, совпадают с ДЗ), `tune_users`
  (2 000, веса смешивания, ранняя остановка сети, λ MMR), `fit_users` (6 000, обучение ранжировщиков).
- Все признаки и модели считаются только по train. Тестовые метки `eval_users` не используются до финального сравнения.

## Ограничения

Случайное, а не временное разбиение; непрочитанное считается нерелевантным; выборка оценок обрезана
(≈100 на книгу), поэтому популярность слабее, чем в реальном сервисе; ранжировщики обучены на тестовых
метках `fit_users`, в продакшене их заменили бы логи показов.
